# Govorun PC

Голосовой ввод на русском для **Windows**. Полностью офлайн, звук никуда не уходит.
Аналог Android-приложения [govorun-lite](https://github.com/amidexe/govorun-lite), только под десктоп.

Под капотом:
* **GigaAM v2** — модель распознавания речи от Сбера (MIT)
* * **sherpa-onnx** — ONNX-рантайм (Apache 2.0)
  * * **xlm-roberta** — восстановление пунктуации офлайн (Apache 2.0)
   
    * ## Возможности
   
    * - 🎤 Запись по хоткею **Alt+X** (настраивается) — нажал, сказал, нажал снова
      - - 📋 Распознанный текст **автоматически вставляется** в активное окно и копируется в буфер
        - - ✏️ **Восстановление пунктуации** — запятые, точки, заглавные буквы
          - - 🖥️ **Системный трей** — работает в фоне, терминал держать открытым не нужно
            - - 🔴 **Индикатор записи** — красный бейдж в углу экрана мигает пока идёт запись
              - - ⚙️ **GUI настроек** — смена хоткея и микрофона без перезапуска
                - - 📴 Полностью офлайн после установки
                 
                  - ## Установка
                 
                  - ```bash
                    # 1. Зависимости
                    pip install -r requirements.txt

                    # 2. Модель GigaAM (~330 МБ, один раз)
                    python download_models.py

                    # 3. Запуск
                    python govorun_pc.py
                    ```

                    Или просто двойной клик на **govorun.vbs** — запустится без окна терминала.

                    ## Использование

                    | Действие | Результат |
                    |---|---|
                    | **Alt+X** | Начать запись |
                    | **Alt+X** ещё раз | Остановить, распознать, вставить текст |
                    | Правый клик на иконке трея | Настройки / Выход |

                    При записи в правом нижнем углу экрана появляется красный мигающий бейдж **● REC**.

                    ## Настройки (GUI)

                    Правый клик на иконке трея → **Настройки**:

                    - **Горячая клавиша** — любая комбинация, например `ctrl+shift+r`
                    - - **Микрофон** — выбор из списка всех устройств ввода
                      - - **Пунктуация** — включить / выключить восстановление знаков препинания
                       
                        - Изменения применяются сразу, без перезапуска.
                       
                        - ## Запуск
                       
                        - | Файл | Описание |
                        - |---|---|
                        - | `govorun.vbs` | Тихий запуск — без окна терминала (рекомендуется) |
                        - | `govorun.bat` | Запуск через cmd |
                        - | `python govorun_pc.py` | Запуск из терминала (видны логи) |
                       
                        - Флаги командной строки:
                       
                        - ```bash
                          python govorun_pc.py --list-devices   # показать все микрофоны
                          python govorun_pc.py --device 2       # выбрать микрофон по номеру
                          python govorun_pc.py --no-punct       # отключить пунктуацию
                          ```

                          ## Автозапуск с Windows

                          1. `Win+R` → введите `shell:startup` → Enter
                          2. 2. Положите туда ярлык на `govorun.vbs`
                            
                             3. ## Если что-то не работает
                            
                             4. **«Модель не найдена»** — запустите `python download_models.py`.
                            
                             5. **Микрофон не пишет** — запустите с флагом `--list-devices`, выберите нужный через `--device N`.
                            
                             6. **Текст не вставляется** — убедитесь что после остановки записи фокус остаётся на нужном окне.
                            
                             7. **Пунктуация не загружается** — при первом запуске xlm-roberta скачивается (~50 МБ) в `~/.cache/govorun/`. Нужен интернет один раз.
